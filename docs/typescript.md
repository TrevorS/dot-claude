### TypeScript / JavaScript

- Prefer **TypeScript** over **JavaScript**.
- Prefer to use `fnm` to manage `Node.js` versions.
- Prefer to use `pnpm` for everything else (`pnpm add`, `pnpm run`, etc...)
- Prefer `const` over `let`, and `let` over `var`.
- Prefer `import` statements instead of `require`.
- Prefer `async/await` for asynchronous code instead of callbacks or promises.
