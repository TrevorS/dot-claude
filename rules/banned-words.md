# Banned Words

Never use the following words or phrases in documentation, commit messages, PR descriptions, READMEs, or code comments. They are hallmarks of AI-generated text. Use plain, direct language instead.

If you catch yourself reaching for one of these, rewrite the sentence — the simpler version is almost always better.

## Banned phrases

Also avoid these patterns:

- "This commit/PR ensures..."
- "This function is responsible for..."
- "Refactor to streamline..."
- "Comprehensive test coverage"
- "Seamless integration"
- "In today's..." / "In the realm of..."
- "It's worth noting that..."
- "It's important to note..."
- "Paving the way for..."
- "A testament to..."
- Comments explaining *what* code does instead of *why*
